Tisková sestava — branding poradce

Hodnoty se použijí v hlavičce a podpisu tiskové sestavy (soubory/tisk.html).

Zobrazí se jako „Připravil: …" v hlavičce a v podpisovém řádku. Při prázdné hodnotě se použije „investiční poradce".

Výchozí logo je již nastavené – pole můžete nechat prázdné a použije se automaticky. Pokud chcete vlastní logo:
1. Otevřete GitHub repozitář a v něm složku soubory/.
2. Add file → Upload files a nahrajte PNG/JPG/SVG.
3. Klikněte na nahraný obrázek a poté na tlačítko Raw.
4. Zkopírujte adresu z prohlížeče (začíná https://raw.githubusercontent.com/…) a vložte sem.
Velikost neřešit – v sestavě se logo automaticky zmenší (max. 180×48 px, ~13 mm na tisku).
